# Held-out TLD v0.2.1 preregistration

These machine-readable files freeze the Beijing PM2.5 domain translation, parent-local nulls, N grids, seeds, perturbations, endpoints, tests, falsifiers, and claim boundary before any real held-out TLD metric is computed.

The selection was frozen at commit `2ff2ddb1a4f656d3c672079a6e8821bf9c3858eb`. The real source archive has been used only for byte custody and schema/member identity at this checkpoint. The synthetic calibration script has no source-file input and confirmed the frozen gates on negative and positive fixtures without reading the held-out data.

`T_e` is the first primary operation depth with observed/null separation. `S_e_contiguous` measures survival after `T_e`. `winner_N` is a separate harmonic closure-mode label. None is a claim of physical time, universal scale, or external validation.
