# Claim levels

| Level | Meaning | TLD I status |
| --- | --- | --- |
| `ILLUSTRATIVE_ANALYTIC` | Declared model or visual analog | The `z^14+c` sandbox only |
| `COMPUTED_DYNAMICAL` | Reproducible registered computation | Historical and modern TLD I lanes |
| `TLD_DERIVED` | Registered ladder and applicable matched-control endpoints satisfy every gate | Blocked |
| `EXTERNALLY_VALIDATED` | Independent held-out external evidence and receipt | Forbidden for this task |

Claim authority is the minimum of the request, engine capability, domain ceiling, profile rules,
and adjudication. A source title, DOI, visual resemblance, or successful execution never promotes a
claim. The historical TLD I source itself has a `COMPUTED_DYNAMICAL` ceiling.

`winner_N` is not `T_e` or `S_e`. The historical reproduction leaves both endpoint fields null.
The modern extension records them as `NOT_APPLICABLE` rather than manufacturing a value. See the
[scientific contract](scientific_contract.md) for the canonical term boundaries.
